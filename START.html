🎮 ShareControl Dashboard

Professional Steam Account Sharing Platform with Real-time Sync

⚡ Quick Start ~10 min

📖 Step 1: Read QUICKSTART.md
Open QUICKSTART.md in your editor or view it on GitHub. It has a complete 10-minute setup guide.
1️⃣ Step 2: Setup Supabase (3 min)
Go to: https://supabase.com
Create: New project
Run: SQL from supabase-schema.sql
Copy: Project URL and Anon Key
2️⃣ Step 3: Get Steam API (2 min)
Go to: https://steamcommunity.com/dev/apikey
Get: Your Steam API Key
Find: Your SteamID64 from your profile URL
3️⃣ Step 4: Configure (1 min)
Edit supabase-config.js lines 3-6 with your credentials:
  • SUPABASE_URL
  • SUPABASE_ANON_KEY
  • STEAM_API_KEY
  • STEAM_ACCOUNT_ID
4️⃣ Step 5: Open Dashboard (4 min)
Double-click sharecontrol-dashboard.html
Dashboard should load and show calendar + reservations

  • Have the SteamID64 of the shared account
  • Text editor open (VS Code recommended)
